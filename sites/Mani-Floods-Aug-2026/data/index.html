This repository contains curated, analysis-ready vector layers, hydrometeorological time series, and validation reports supporting the post-event physical reconstruction of the extreme flash flood event of August 15, 2026, across the Mani Peninsula, Peloponnese, Greece.

The repository is hosted at:

https://evelpidou.nkua.cloud/Mani-Floods-Aug-2026/data

The companion reproducible source code repository is hosted at:

https://evelpidou.nkua.cloud/Mani-Floods-Aug-2026/src

1. Spatial and Vertical References

  • Horizontal Coordinate Reference System (CRS): Greek Grid (GGRS87 / EPSG:2100).
  • Projection: Transverse Mercator
  • Central Meridian: 24° E
  • False Easting: 500,000 m; False Northing: 0 m
  • Scale Factor: 0.9996
  • Ellipsoid: GRS 1980
  • Vertical Reference Datum: Mean Sea Level (MSL), tied to the national tide gauge benchmark at Piraeus (Hellenic Military Geographical Service - HMGS).

2.1 Vector Layers (vector/)

All vector layers are formatted as OGC GeoPackage (.gpkg) files in projected coordinate reference system EPSG:2100.

mani_catchment_basins.gpkg

  • Layer name: mani_catchment_basins
  • Feature count: 266 polygons
  • Delineation methodology: Hydrologically conditioned high-resolution digital elevation model routing using the deterministic eight-neighbor (D8) algorithm (O'Callaghan & Mark, 1984; Jenson & Domingue, 1988) with sink filling (Wang & Liu, 2006).
  • Attribute schema:
  • basin_id (Integer): Unique identifier for each discrete drainage catchment ($1 \dots 266$).
  • flank (String): Receiving marine basin verified by downstream flow routing. Values: West (Messenian Gulf, 139 basins) or East (Laconian Gulf, 127 basins).
  • area_sqkm (Real): Planimetric catchment drainage area ($A$) in square kilometers.
  • perimeter_km (Real): Planimetric perimeter of the catchment boundary in kilometers.
  • mean_slope_pct (Real): Hypsometrically weighted mean slope gradient across the basin (percent).
  • melton_ruggedness (Real): Melton Ruggedness Number computed as $M_R = \Delta H \cdot A^{-0.5}$, where $\Delta H$ is relief ($H_{\max} - H_{\min}$) in kilometers (Melton, 1965).

mani_regional_divide.gpkg

  • Layer name: Regional_Drainage_Divide
  • Feature count: 1 linestring (total length: 95.52 km)
  • Topological definition: Continuous regional drainage divide separatrix tracing the main spine of the Mani Peninsula from Mount Taygetos through Sangias Ridge down to Cape Tainaron. It forms the exact shared boundary between the aggregated West flank basins and East flank basins, satisfying strict spatial topology ($C = \partial \Omega_{\text{West}} \cap \partial \Omega_{\text{East}}$).

mani_stream_network.gpkg

  • Layer name: mani_stream_network
  • Geometry: MultiLineString
  • Channel extraction: Derived from D8 upslope contributing area with an initiation threshold of $>1000$ cells (2.5 ha). Features are classified by Strahler stream order ($1 \dots 5$).

2.2 Hydrometeorological Time Series (timeseries/)

ground_station_hyetographs_10min.csv

Continuous 10-minute precipitation time series recorded during the synoptic passage of the mesoscale convective system (August 14–17, 2026) across automated weather stations (Lagouvardos et al., 2017).

  • timestamp_utc: ISO 8601 UTC timestamp (YYYY-MM-DDTHH:MM:SSZ).
  • station_id: Unique identifier (e.g., kokkala, kardamyli, areopoli, kalamata_airport, kythira_airport, tripolis_airport).
  • precip_rate_mm_hr: Instantaneous rainfall intensity (mm h⁻¹).
  • accumulated_precip_mm: Cumulative precipitation recorded from 2026-08-14 00:00:00 UTC (mm).

ground_stations_august2026.csv

Geographic metadata and storm-total accumulations for the regional meteorological monitoring network.

  • station_id: String identifier.
  • station_name: Station name.
  • latitude, longitude: WGS 84 geographic coordinates.
  • easting_ggrs87, northing_ggrs87: EPSG:2100 coordinates (meters).
  • elevation_m: Elevation above sea level (meters).
  • total_precip_24h_mm: Cumulative 24-hour rainfall recorded during the peak event window (August 15, 2026).

2.3 Physical Reconstruction and Validation Reports (reports/)

target_catchments_flood_reconstruction.json

Comprehensive hydrodynamic and physiographic parameters for the 4 severely damaged ungauged catchments (Kokkala, Kotronas, Limeni, Areopoli). Contains:

  • Basin area ($A$, $\text{km}^2$), flow path length ($L$, $\text{km}$), and channel gradient ($S_0$).
  • Time of concentration ($t_c$) calculated via Giandotti and Kirpich formulations.
  • Green–Ampt infiltration parameters: hydraulic conductivity ($K_{\text{sat}}$), matric suction head ($\psi$), moisture deficit ($\Delta \theta$).
  • Peak runoff discharge ($Q_p$, $\text{m}^3\,\text{s}^{-1}$) from post-wildfire SCS-CN and hydrodynamic routing.
  • Critical bed shear stress ($\tau_b$, $\text{N}\,\text{m}^{-2}$), unit stream power ($\omega$, $\text{W}\,\text{m}^{-2}$), and maximum transportable boulder diameter ($D_{\max}$, $\text{m}$) computed via the Shields criterion (Shields, 1936; Costa, 1983).

empirical_validation_report.json

Binary contingency metrics validating model predictions against the official emergency declarations issued by the Region of Peloponnese and Hellenic Civil Protection:

  • Critical Success Index (CSI / Threat Score)
  • Probability of Detection (POD / Hit Rate)
  • False Alarm Ratio (FAR)
  • Accuracy Score

run_manifest.json

Full computational provenance record including environment configuration, package versions, random seeds, and SHA-256 checksums of all input datasets.

2.4 Metadata and Provenance (metadata/)

  • data_catalog.json: Machine-readable metadata conforming to DCAT-AP and STAC item specifications.
  • inventory.csv: Complete audit log of all 6,700+ raw and intermediate files, including source URLs, licenses, SHA-256 hashes, and spatial bounding boxes.
