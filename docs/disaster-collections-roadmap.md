# Disaster collections roadmap

The user authorized publication and completion of the four collections proposed
on 7 September 2026. The finite scope is:

1. Landslides — published as release `20260907-landslides`; 2,122,083 source records.
2. Tsunamis — published as release `20260907-tsunamis`; 37,027 source records from NOAA and the Greek impact database.
3. Wildfires and burned areas — published in release `20260907-wildfires-earthquakes`; 137,028 EFFIS and MTBS boundaries.
4. Earthquake impacts — published in the same release; 15,811 NOAA and USGS source records.

Each collection uses the existing NKUA WebGIS components: map, source colours,
clustering, filters, search, numerical and categorical statistics, record modals,
definition, references, submission information, university branding, icons and
social metadata. Original identifiers, provenance, uncertainty and reuse terms
remain visible. Coincident records are not merged merely by proximity.

The final publication command completed successfully on 7 September 2026.
The four homepage cards use map-interface previews; social artwork is separate.
See `releases/2026-09-07-disaster-completion.md` for the requirement evidence and
the limits of the checks performed.

No new test, build, linter, type, status/diff or browser verification runs are
authorized by the publication request. Static assets are published through a
persistent release mount using the existing image, with prior releases retained.
